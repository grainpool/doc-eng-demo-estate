## sessions run

Ask a question in plain language.

```
Usage: relay sessions run [options] <sessionId> <prompt>

Send a natural-language prompt to a session. The prompt is translated to ONE
bounded analysis operation (or refused); the kernel never runs model-authored
code.

Arguments:
  sessionId                      session id (ses_…)
  prompt                         the question, quoted

Options:
  --input-artifact <artifactId>  run on a previous derived table instead of the
                                 file
  -h, --help                     display help for command

Examples:
  $ relay sessions run ses_01abc "which columns correlate?"
```
