# doc-eng-demo-estate

The documentation estate for the [Relay + Concord demo](https://github.com/grainpool/doc-eng-demo).

This repository holds documentation surfaces only — no code, no CI, and **no `.github/` directory, ever**.
That absence is a security property, not an oversight: an automated system (**Concord**, a documentation
reconciliation engine) holds `Contents: write` here through a GitHub App, and because this repository
contains no workflows, no privileged CI is reachable from any branch it (or anyone) pushes. All
application code, product truth, and CI live in the main repository, which mounts this one as a git
submodule at `estate/`.

## What happens in this repository

When a product fact changes in the main repo (an upload limit, platform availability, a retention
window), Concord detects the drift between product truth and these pages, validates a patch against
mechanical gates (evidence resolution, anti-hallucination extraction, a path allowlist), and opens a
**pull request** on a `concord/run-*` branch. The PR body lists the fact deltas, the evidence for each
patch, and a link to the public run inspector at
[concord.otonieltrejo.com](https://concord.otonieltrejo.com). A human reviews and merges; branch
protection on `main` means nothing lands without a PR. Stale run branches are closed and deleted by a
cleanup cron after 48 hours.

## Layout

| Directory | Surface |
|---|---|
| `docs-mintlify/` | Developer documentation, published to [docs.otonieltrejo.com](https://docs.otonieltrejo.com) via Mintlify |
| `docs-mintlify/generated/` | Machine-generated pages (availability matrix, plan gating, navigation fragment) — regenerated, never hand-edited |
| `help-center/` | End-user help center (a fixture surface — Intercom integration is a deliberate non-goal of the demo) |
| `in-product-copy/` | In-product copy registry (typed JSON, imported by the Relay web client at build time) |
| `cli-docs/` | CLI reference (regenerated from CLI introspection in the main repo; not PR-writable) |
| `release-notes/` | Release notes (append-only records) |

Files marked `generated: true` (or carrying a `GENERATED BY CONCORD` header) are derived artifacts:
edit the source facts in the main repository instead, and let regeneration produce the page.
Line endings are LF throughout (`.gitattributes`) — generated files are compared byte-for-byte
against generator output to detect hand edits.
