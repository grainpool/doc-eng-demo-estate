# How do I run an analysis?

1. Open your project and click **Analyze** next to a file.
2. Type a question in plain language — "which columns correlate?", "show rows where region is A", "plot a histogram of score".
3. Relay picks exactly one supported operation and runs it. The result appears in the session, and everything is saved as an artifact automatically.

If Relay says a question isn't supported, that's expected for anything outside
its eight statistical operations — it will suggest the closest supported ones.
