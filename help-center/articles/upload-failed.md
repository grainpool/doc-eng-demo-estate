# Why did my upload fail?

Two things can stop an upload, and the error message tells you which one you hit.

**The file type isn't supported.** Relay reads `.csv` and `.tsv` files. If you're
starting from Excel, use *File → Save As → CSV* and upload that instead.

**The file is too big.** Files need to be smaller than 10 MB — if yours is
bigger, try splitting it by date range or dropping columns you don't need.

If neither applies and the upload still fails, the service itself may be having
trouble — try again in a minute.
